# CancerResearchTool Prototype

This is a prototype GUI application built with Python and Tkinter intended for educational and research simulation purposes in the bioinformatics domain.

## Setup
1. `pip install -r requirements.txt` (Currently only requires built-in libraries)
2. `python app.py`

## Build .exe
Run `pyinstaller --onefile --noconsole --name "CancerResearchTool" app.py`
